# Wiki

The active collection is [wiki/index.norg](wiki/index.norg), written in Neorg format.
It is a personal command cookbook for development, shells, databases, and system administration.

The `vimwiki/` directory is the legacy copy. Add and update recipes in `wiki/`.

Keep each recipe short: a task heading, a Neorg `@code` block with its language,
one useful caveat, and links to related pages or official documentation. Label platform
or shell assumptions and use example values rather than credentials.
